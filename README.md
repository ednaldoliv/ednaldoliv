## Sobre mim

Sou formado em **Análise e Desenvolvimento de Sistemas pelo IFCE**, com foco em **desenvolvimento backend**. Trabalho com JavaScript, TypeScript, Node.js e bancos de dados relacionais, além de desenvolver interfaces quando o projeto exige.

Tenho interesse em **APIs, arquitetura de software e boas práticas de desenvolvimento**. Busco aprender continuamente e aplicar esse conhecimento em projetos práticos.

Fora do código, gosto de jogos e mangás — interesses que também fazem parte da minha identidade.
